    Download this week’s file
    Set up the iPhone Shortcuts (one-off, about 5 minutes)

    The NSW Valuer General publishes a sales file every Monday. These two shortcuts download the files into a folder in the Files app. You then tap Import sales files above and select everything in that folder. Files already imported are merged, not doubled up. All NSW sales are kept, so you can search anywhere in the state.

    First, in the Files app: open iCloud Drive › Shortcuts and create a folder called NR Prices.

    1. “NR Prices weekly” (downloads each new week automatically)

    In the Shortcuts app, tap +, name it NR Prices weekly, and add these actions in order:

    1. Date, set to Current Date.
    2. Adjust Date: Subtract 1 day from the date. (The automation runs on Tuesdays, so this gives Monday.)
    3. Format Date: Date Format Custom, format string yyyyMMdd.
    4. Text: https://www.valuergeneral.nsw.gov.au/__psi/weekly/ then insert the Formatted Date variable, then .zip.
    5. Get Contents of URL, using the Text.
    6. Set Name of the Contents of URL to Formatted Date followed by .zip.
    7. Save File: turn Ask Where to Save off and set the folder to Shortcuts/NR Prices.
    8. Show Notification: “New sales file ready. Open NR Prices and import it.”

    Then go to the Automation tab › + › Time of Day: 7:00 am, Weekly, Tuesday, choose Run Immediately, and pick NR Prices weekly.

    2. “NR Prices catch-up” (builds the history, and fills in missed weeks)

    1. Get Clipboard.
    2. Split Text by New Lines.
    3. Repeat with Each item in Split Text, and inside the repeat:
      1. Get Contents of URL, using the Repeat Item.
      2. Save File: Ask Where to Save off, folder Shortcuts/NR Prices.

    To use it, tap Copy links of files still to download above, then run NR Prices catch-up. The first time, this downloads the 2024 and 2025 yearly files (large: use Wi-Fi) plus every week so far this year.

    If a shortcut saves a file the app can't read, that week usually just isn't published yet. The app skips it.

    How property types are worked out
    • Unit / townhouse: strata title.
    • House in town: residential or village zoning (R1–R4, RU5), not vacant.
    • Vacant block (town): town zoning, recorded as vacant land.
    • Rural lifestyle / acreage: rural, large-lot residential (R5) or conservation zoning, or 4,000 m²+ outside town zones, under 40 ha.
    • Farm: 40 ha or more of rural land, or recorded as farming use on 10 ha+.
    • Commercial / other: business, industrial or special-use zoning or use.
